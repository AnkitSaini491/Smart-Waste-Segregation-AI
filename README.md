# Smart Waste Segregation AI ♻️

An AI-powered Computer Vision application that
automatically classifies waste images into different
categories using Deep Learning.

## Features
- Waste image classification
- Plastic, Paper, Glass, Metal and Organic detection
- Deep Learning using MobileNetV2
- Image upload interface
- Prediction confidence score
- Smart waste disposal suggestions

## Technologies
- Python
- TensorFlow
- OpenCV
- NumPy
- Streamlit
- MobileNetV2

## Installation

pip install -r requirements.txt

## Train Model

python train.py

## Run Application

streamlit run app.py
